# Start here

1. Open [the presentation PDF](deliverables/Tayseer_Executive_Story.pdf) to see the complete story.
2. Download [the PowerPoint](deliverables/Tayseer_Executive_Story_Final.pptx) to present. The slides are English. The short Arabic notes appear only in Notes or Presenter View.
3. Read [the one-page Arabic speaking notes](deliverables/Tayseer_Presenter_Notes_AR.pdf).
4. Download [the packaged Tableau workbook](tableau/Tayseer_Investment_Dashboard.twbx). Open it in the Tableau desktop app, select the dashboard, and use its four worksheets for supporting evidence.
5. Open [the executed notebook](analysis/capstone_analysis.ipynb) to inspect the calculations or rerun them.
6. Use [the requirements checklist](docs/REQUIREMENTS_CHECKLIST.md) before presenting.

GitHub previews the PDFs and notebook. For PowerPoint and Tableau, click the file, then download the raw file. A Tableau workbook opens in Tableau rather than in the GitHub page.

The decision is SAR 40M across eight lagging regions: SAR 35M for the four widest gaps and SAR 5M for the other four. National adoption is 66.21%, but eight regions remain below 65%.
